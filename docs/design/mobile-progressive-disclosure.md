# Mobile Progressive Disclosure

MoneyKai keeps the next financial decision visible and moves optional configuration behind a
plain-language disclosure or a dedicated screen. Disclosure never conceals the amount affected,
sync/offline status, why a permission is needed, a destructive consequence, or the route to privacy
controls.

| Surface | Immediately visible | Revealed when requested |
|---|---|---|
| Login | Brand, Google sign-in, account creation | Email/password and recovery |
| Dashboard | Available amount, income, spending, budget state, sync exception, recent activity | Budget calculation context |
| Transactions | Search, income/expense scope, results, add action | Multi-field filters and sorting |
| Budget | Remaining amount, spent amount, allowance, category chart | Category ceilings, reset rules, emergency mode, adjustments |
| Groups | Existing groups, totals, archive state | Creation form and destructive group controls |
| Account | Identity and sync state | Recovery and security routes |
| Trust Center | Control promise and data-control route | Data use, capture permission, local/cloud explanations |
| Settings | Sync state, account, Trust Center | Backup, restore, password reset, testing, sign-out controls |

The active More hub is a navigation surface, not a catalogue. It exposes Account, Shared Expenses,
Trust Center, Settings, and Notifications. Experimental AI, subscriptions, savings challenges,
notes, learning, and auto-capture promotion are excluded from the V1 hub while their legacy routes
remain untouched for later product decisions.
