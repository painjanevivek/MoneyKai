## Delivered Decision

[Android V1 KPI Framework](../../../product/kpi-framework.md) version 1.0.0 defines three primary
KPIs with formulas, populations, windows, provisional targets, decisions, and owners. It separately
defines diagnostic drivers, comprehension-based trust measures, support measures, non-negotiable
guardrails, a privacy-minimized event contract, data-quality rules, and operating cadence.

The framework follows the KPI-design discipline of using a small decision set with drivers and
guardrails. It records that no production baseline exists rather than inventing one. M14/M15 must
measure and approve or tighten provisional targets; constitutional gates cannot be relaxed by an
analytics result.
