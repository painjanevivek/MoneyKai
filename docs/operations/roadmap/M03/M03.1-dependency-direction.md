## Delivered Decision

[MoneyKai Application Dependency Direction](../../../architecture/application-dependency-direction.md)
and [ADR-002](../../../architecture/decisions/adr-002-modular-application-boundaries.md) establish:

- the active Android, web, native-host, FastAPI, edge, Flutter-reference, and duplicate-tree status;
- the required `UI -> application -> domain/ports <- adapters <- platform` direction;
- API schema/transport authority and backend-only financial writes;
- storage and authentication ownership by data class and trust boundary;
- the only standing exception classes and a task-owned migration ledger; and
- the M03.2–M03.5 execution and CI-enforcement sequence.

The documents distinguish observed transitional state from the accepted target. They do not claim
that direct storage/network/Firebase imports, duplicate financial rules, or duplicate route trees
have already been removed.

## Scope and Preconditions

- In scope: architecture and ADR documentation, this evidence record, and the M03.1 ledger link.
- Out of scope: runtime refactors, package moves, dependency installation, deletion of transitional
  sources, and CI enforcement; these remain M03.2–M03.5.
- Preconditions: accepted canonical API ADR, API governance documents, M02 route inventory, code
  ownership, and the repository state at the base revision.
- Rollback: revert this documentation commit before implementation depends on it; after that, amend
  through a superseding ADR rather than silently changing direction.
