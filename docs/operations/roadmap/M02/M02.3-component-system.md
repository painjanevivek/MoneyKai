## Residual Risk

The production components compile and their pure contracts pass, but primary screens still contain
legacy layouts, copy, direct icons, raw visual constants, and feature-heavy disclosure. M02.4 must
apply this system to the V1 journeys without dropping existing domain behaviour. M02.5 must validate
the rendered dock, focus order, TalkBack, font scaling, reduced motion, target geometry, contrast,
and solid glass fallback on supported Android devices. Gradle emitted dependency deprecation and
cross-drive hard-link fallback warnings; neither affected the successful APK build, and dependency
modernization remains owned by M07/M12.
