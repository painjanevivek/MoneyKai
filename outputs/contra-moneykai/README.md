# MoneyKai Contra case-study assets

All screen data is fictional and anonymized. The case study reflects features evidenced in the MoneyKai repository; it does not make performance, customer, or growth claims.

| File | Screen | What it communicates |
| --- | --- | --- |
| `01-cover.png` | 1600×900 Contra cover | The MoneyKai thesis: a calm, review-first finance workspace with a portfolio lens. |
| `02-dashboard.png` | Desktop portfolio overview | Net worth, tracked allocation, performance context, holdings, and a non-advisory portfolio review. |
| `03-portfolio-detail.png` | Holding detail | Mutual-fund value, allocation context, historical value, and SIP/dividend transaction context. |
| `04-core-flow.png` | Savings predictor and challenges | The strongest planning flow implemented today: compare a current trajectory against category-level adjustments, then optionally start a challenge. |
| `05-mobile.png` | 390px portfolio review | The most compelling portfolio view, compacted for MoneyKai’s mobile-first product. |
| `06-wireframe-to-product.png` | Process comparison | How real product constraints and the MoneyKai design system shaped the final interface. |

## Upload these three to Contra first

1. `01-cover.png` — strongest art direction and the clearest initial positioning.
2. `02-dashboard.png` — demonstrates dense, credible fintech information design at a glance.
3. `04-core-flow.png` — proves the work is anchored in a thoughtful, real user workflow rather than just a dashboard.

Use `03-portfolio-detail.png`, `05-mobile.png`, and `06-wireframe-to-product.png` deeper in the case study to establish system depth, responsive thinking, and process.
